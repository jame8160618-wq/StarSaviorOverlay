# StarSaviorOverlay

《星之救援者（Star Savior）》事件查詢 Overlay 工具，支援螢幕畫面擷取與 OCR 辨識、事件關鍵字搜尋，以及啟動時背景自動同步與防呆備援。

## 下載與使用（一般玩家）

1. 前往本儲存庫的 **Releases** 頁面，下載最新版本的 `.zip` 壓縮檔（例如 `StarSaviorOverlay_v2.zip`）。
2. 將 `.zip` 解壓縮到本機資料夾（建議不要放在需要系統管理員權限的系統目錄）。
3. 確認資料夾內包含主執行檔（`.exe`）、`events_tc.json` 與 `使用說明.txt`。
4. 雙擊執行程式即可使用；若在全螢幕遊戲中快捷鍵無法觸發，請改以**系統管理員身分執行**。

## 環境需求與注意事項

- **Windows OCR 繁體中文語言包（`zh-Hant-TW`）**：本工具使用 Windows 內建 OCR 辨識繁體中文。若辨識失敗或無反應，請先確認系統已安裝繁體中文（台灣）語言與 OCR 功能。
- **全螢幕／防作弊視窗權限**：部分遊戲在全螢幕或高權限視窗下，一般權限可能無法攔截全域熱鍵或顯示覆蓋層，建議以系統管理員身分啟動工具。
- **事件資料庫更新**：啟動時會在背景檢查與同步事件資料（`events_tc.json`）；若網路暫時無法連線，仍會使用本機現有資料維持查詢。

## 原始碼與開發說明

本儲存庫包含以下主要檔案：

- `overlay_ocr.py`：主程式原始碼（畫面擷取、OCR 辨識、事件比對／搜尋、Overlay 介面與背景同步邏輯）。
- `events_tc.json`：繁體中文事件資料檔。
- `.gitignore`：排除虛擬環境、打包產物、快取與本機設定／暫存檔。

若需從原始碼自行執行或打包，請建立 Python 虛擬環境並安裝相依套件（如 `opencc`、`winocr`、`rapidfuzz`、`mss`、`Pillow`、`keyboard`、`requests` 與 `pyinstaller`）。
